# StyleDNA

> A Machine Learning application that builds personal style profiles
> and generates outfit recommendations based on aesthetic preferences.


## What It Does
StyleDNA analyzes clothing attributes, such as color, category, season, and style tags, to cluster items into aesthetic profiles. It then uses those profiles to recommend outfit combinations tailored to each user's unique style DNA.


## Tech Stack
- Python
- Jupyter Notebook
- pandas
- scikit-learn
- matplotlib
